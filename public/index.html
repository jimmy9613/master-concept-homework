Google Maps JavaScript API 練習

1. 熱力圖

以台北熱門地點產生約 1,500 個資料點，用 deck.gl HeatmapLayer 畫成熱力圖，可調整半徑與強度。

2. 點擊查地址

點擊地圖任意位置，放上標記並透過反向地理編碼顯示該位置的地址。

3. 標記聚合

在全台 8 個城市放 100 個標記，縮小地圖時自動合併成聚合點。

4. 路線規劃

輸入起訖點、選擇走路 / 開車 / 大眾運輸，畫出路線並顯示時長與距離。

5. 訊息查證

先檢索 Google 新聞、Cofacts、維基百科的最新資料，再由 Gemini 判斷網路流傳訊息的真偽並附上來源。
執行前準備
  1. 到 Google Cloud Console 建立 API 金鑰，並啟用 Maps JavaScript API、Geocoding API、Routes API，填入 public/config.js。
  2. （功能 5）到 Google AI Studio 申請 Gemini 金鑰，把 .env.example 複製成 .env，填入 GEMINI_API_KEY。
  3. 在專案資料夾執行 npm install（第一次），再執行 npm start，用瀏覽器開啟 http://localhost:8000。
每一題的解題思路請見 📘 解題說明；完整的執行方式與常見問題請見 README.md。
